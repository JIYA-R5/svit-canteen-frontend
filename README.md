# SVIT Canteen Frontend
A responsive frontend web application for the SVIT Canteen that helps students view menu items and access canteen information through a simple and user-friendly  interface  wwith a clean and responsive design.
## Features
- Digital menu
- Easy navigation
- Mobile friendly
